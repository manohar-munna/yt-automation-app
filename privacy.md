# Privacy policy

_Last updated: 18 November 2026_

yt-automation-app is a personal tool used by one creator to manage their own YouTube channels. It is not a public service.

## What data it accesses
With the channel owner's consent through Google OAuth, the app requests two scopes:

- `youtube.upload` lets it upload videos to the authorized channel.
- `youtube.readonly` lets it read the channel's name, ID, video list and basic statistics.

## How the data is used
The data is used only to upload the owner's own videos (always as private) and to read the channel's information and performance. The app does not sell, share or transfer any data to third parties, and does not use it for advertising.

## Storage
OAuth tokens are stored only on the owner's private server, in a folder readable only by the owner. No YouTube data is stored beyond what the owner keeps for their own work.

## Revoking access
You can remove the app's access at any time at <https://myaccount.google.com/permissions>. The owner can also delete the stored tokens.

## Google API Services User Data Policy
The app's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Contact
Questions can be raised as an issue on this repository.
